Nothing happens behind your back

See first. Undo anything. Keychain stays. These are the rules iClearer follows, every time.

  • You decide every cleanup

    Nothing is cleaned automatically. iClearer shows what it found, and you pick what goes.

  • Everything goes to the Trash

    Nothing is permanently deleted. Undo works right away, and History keeps every cleanup so you can restore anything.

  • Some things can’t be selected

    Keychain, accounts, editor data, passwords and keys in developer folders, and git repositories are off limits. You can add your own.

  • It checks your backup first

    Before removing something that can’t be rebuilt, iClearer checks Time Machine and warns you if there is no recent backup.

  • It stops when it’s unsure

    On a macOS version iClearer hasn’t been tested on, it can still scan, but cleaning is switched off until you update.

  • You can read the rules

    Our cleanup rules are public: the categories iClearer cleans and how each is labelled.

What we collect. Your email, your plan and a hashed ID of your Mac, so we can manage your license seats. We never collect your files, file names or scan results. We only email you about updates and new products if you opt in.

Install iClearer

Download the DMG, then clear the first-open warning if macOS asks.

  1. Download the DMG and drag iClearer into Applications.
  2. The first time, right-click iClearer and choose Open. Do not click Move to Trash.
  3. Or click Done, then System Settings → Privacy & Security → Open Anyway.

Download iClearer.dmg

Open Terminal and paste one of these commands

If the DMG is in Downloads (newest file)
DMG=$(ls -t ~/Downloads/iClearer*.dmg 2>/dev/null | head -1)
MNT=$(mktemp -d /tmp/iclearer-mnt.XXXXXX)
hdiutil attach "$DMG" -nobrowse -quiet -mountpoint "$MNT"
rm -rf /Applications/iClearer.app
ditto "$MNT/iClearer.app" /Applications/iClearer.app
xattr -cr /Applications/iClearer.app
hdiutil detach "$MNT"
rmdir "$MNT" 2>/dev/null || true
open /Applications/iClearer.app
If the app is already in Applications
xattr -dr com.apple.quarantine /Applications/iClearer.app && open /Applications/iClearer.app
One-line install
curl -fsSL https://iclearer.com/downloads/install-iclearer.sh | bash

Questions? Answers.

What is iClearer?

iClearer is a Mac cleaner app for macOS 13 or later. It finds the hidden caches, logs, app leftovers, developer files and large files filling your Mac, shows how much space each one uses, and moves what you choose to the Trash. Scanning is free. More about iClearer.

My Mac storage is full. What should I do?

Open System Settings → General → Storage to see what is using the space. Then clear app caches and logs, old downloads, leftovers from apps you removed, and large files you no longer need. iClearer finds all of these in one scan and labels each item Safe or Ask first. For the manual steps, read Mac storage full? How to free up space safely.

How do I clear System Data on a Mac?

System Data is mostly caches, logs, temporary files, Time Machine local snapshots and files left behind by apps. You can’t delete the category itself, but you can shrink it by restarting your Mac and clearing those files. iClearer lists them with their sizes. The full steps are in how to clear System Data on Mac.

Is it safe to delete caches on a Mac?

Yes. Caches are copies of data that apps and macOS rebuild when they need them. The first launch after clearing can be a little slower. iClearer labels rebuildable caches as Safe and moves them to the Trash, so you can still undo.

Does iClearer clean developer caches like Xcode, npm and Docker?

Yes. The Builders pack finds npm, pnpm, Yarn, pip and Homebrew caches, Xcode DerivedData, CocoaPods and Gradle caches, Cursor and VS Code caches, iOS Simulator data, Docker data and Ollama models. API tokens, SSH keys, .env files and git repositories can never be selected. See free up disk space on a Mac for developers.

Is iClearer safe?

Everything it removes goes to the Trash first, so you can undo it. Keychain, accounts and editor user data can never be deleted.

What do Safe and Ask first mean?

Safe items are caches your Mac rebuilds by itself. Ask first items are larger or system-related, so they start unticked and wait for you.

Which Macs does it work on?

iMac, Mac mini, Mac Studio, MacBook Air and MacBook Pro, Intel and Apple silicon. Apple displays are monitors, not Macs, so they don’t count.

What does the free plan include?

Unlimited scans that show what was found by category, with sizes and Safe or Ask first labels, plus 500 MB of cleanup in total. Item names, details, locations and the other tools come with iClearer.

Does iClearer scan for malware?

No. iClearer frees up space. It isn’t an antivirus and doesn’t scan for malware or viruses.
