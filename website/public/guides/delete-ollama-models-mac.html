How to delete Ollama models on Mac

Updated 12 November 2026 · By the iClearer team

Short answer

Ollama stores models on a Mac in ~/.ollama/models. To delete one, run ollama list to see each model and its size, then ollama rm followed by the model name, for example ollama rm llama3.2. Models are safe to delete. To use one again you download it again with ollama pull.

Ollama

List your models with their sizes:

ollama list

Delete one:

ollama rm llama3.2

See the total on disk:

du -sh ~/.ollama/models

Use ollama rm rather than deleting files in Finder. Models share layers with each other, and Ollama only removes the files no other model still uses.

Move Ollama models to another drive

If you want to keep your models but not on the startup disk, set the OLLAMA_MODELS environment variable to a folder on an external drive. For the Ollama Mac app:

launchctl setenv OLLAMA_MODELS /Volumes/External/ollama-models

Quit and reopen Ollama afterwards. The setting lasts until you restart your Mac, so run the command again after a restart. Models you already downloaded stay in the old folder until you move or delete them.

LM Studio

LM Studio keeps models in ~/.lmstudio/models. Older versions used ~/.cache/lm-studio/models. Delete models from the My Models view in the app, which shows the size of each.

Hugging Face cache

Python libraries such as Transformers and Diffusers download models to ~/.cache/huggingface/hub. Check the size:

du -sh ~/.cache/huggingface

Choose what to delete from an interactive list:

huggingface-cli delete-cache

Deleting the folder is also safe. Models download again when a script asks for them.

Frequently asked questions

Where does Ollama store models on a Mac?

In ~/.ollama/models, inside your home folder. The blobs folder holds the model data and the manifests folder records which files belong to which model. You can change the location with the OLLAMA_MODELS environment variable.

How do I delete an Ollama model?

Run ollama list to see the installed models, then ollama rm followed by the name, for example ollama rm llama3.2. Ollama removes the model’s files unless another model still uses them.

Is it safe to delete the ~/.ollama/models folder?

Yes, but it removes every model at once. Nothing else breaks; you download models again with ollama pull. To remove just some models, use ollama rm instead.

How much disk space do local AI models use?

Usually between 2 GB and 50 GB each, depending on the model size and quantization. A few models can easily use more space than everything else in your home folder.

Can I move Ollama models to an external drive?

Yes. Set OLLAMA_MODELS to a folder on the external drive, for the Mac app with launchctl setenv OLLAMA_MODELS followed by the path, then restart Ollama. The drive must be connected whenever you use Ollama.
