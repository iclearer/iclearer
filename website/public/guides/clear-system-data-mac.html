How to clear System Data on Mac

Updated 12 November 2026 · By the iClearer team

Short answer

System Data is the catch-all category in Mac storage for files macOS does not sort anywhere else: caches, logs, temporary files, Time Machine local snapshots, swap files and files left behind by apps. You cannot delete the category directly. You shrink it by restarting your Mac, clearing ~/Library/Caches and ~/Library/Logs, removing Time Machine local snapshots, and deleting leftovers from apps you uninstalled.

What System Data is

Open System Settings → General → Storage and you will see a grey section called System Data. On older versions of macOS it was called “Other”. It contains:

  • App caches, system caches and temporary files
  • Log files
  • Time Machine local snapshots
  • Virtual memory (swap) files and the sleep image
  • App support files, plug-ins and extensions, including files left by apps you deleted

It is separate from the macOS category, which is the operating system itself and should be left alone.

1. Restart your Mac

Start here because it costs nothing. A restart deletes temporary files and resets the swap files macOS builds up when memory runs low. If your Mac has been on for weeks, this alone can return several gigabytes.

2. Clear caches and logs

  1. Quit your open apps.
  2. In Finder, press Shift Command G, type ~/Library/Caches and press Return.
  3. Press Command J and tick Calculate All Sizes.
  4. Move the contents of the largest folders to the Trash.
  5. Do the same in ~/Library/Logs, then empty the Trash.

Apps rebuild their caches the next time you open them. More detail in how to clear cache on Mac.

3. Remove Time Machine local snapshots

If you use Time Machine, macOS keeps local snapshots on your startup disk so you can restore files when the backup drive is not connected. macOS deletes them automatically when it needs space, but you can remove them yourself. Open Terminal and list them:

tmutil listlocalsnapshots /

Delete one by its date stamp:

sudo tmutil deletelocalsnapshots 2026-11-01-093000

Or ask macOS to free about 20 GB of snapshot space:

tmutil thinlocalsnapshots / 20000000000 4

Note: local snapshots are not your Time Machine backup. Deleting them does not touch the backups on your external drive.

4. Delete leftovers from apps you removed

When you drag an app to the Trash, its support files stay behind. Check these folders for names of apps you no longer have:

  • ~/Library/Application Support
  • ~/Library/Containers
  • ~/Library/Caches

Only delete a folder if you are sure the app is gone. The full list of locations is in how to uninstall apps on Mac completely.

5. Find what is still large

This Terminal command lists the 15 largest folders in your Library, biggest last:

du -sh ~/Library/* 2>/dev/null | sort -h | tail -15

Common results are developer tools (Xcode, Docker, simulators), downloaded AI models and message attachments. If you write code, see free up disk space on a Mac for developers.

What you should not delete

  • Anything in /System, /usr or /private/var/vm. macOS manages these.
  • ~/Library/Keychains, which holds your passwords.
  • Application Support folders for apps you still use. They hold your data, not cache.

Frequently asked questions

Why is System Data so large on my Mac?

The usual causes are app caches, Time Machine local snapshots, swap files from running low on memory, and files left behind by apps you deleted. Developer tools such as Xcode and Docker can also add tens of gigabytes.

Can I delete System Data on a Mac?

Not as a single item. System Data is a category, not a folder. You reduce it by clearing caches and logs, removing Time Machine local snapshots, deleting leftovers from uninstalled apps, and restarting your Mac.

How much System Data is normal on a Mac?

Apple does not publish a figure. A few tens of gigabytes is common. It is worth investigating when System Data is far larger than that or keeps growing week after week.

Does restarting a Mac reduce System Data?

Yes. A restart removes temporary files and resets the swap files macOS creates when memory runs low, which are both counted as System Data.

Is System Data the same as macOS in the storage bar?

No. The macOS category is the operating system and should not be touched. System Data is everything else macOS cannot sort into a category, such as caches, logs and snapshots.
