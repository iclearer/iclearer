How to delete Time Machine local snapshots on Mac

Updated 12 November 2026 · By the iClearer team

Short answer

Time Machine local snapshots are copies of recent changes that macOS keeps on your startup disk for about 24 hours. macOS deletes them automatically when it needs space, but you can remove them yourself. List them with tmutil listlocalsnapshots /, then delete one with sudo tmutil deletelocalsnapshots followed by its date. Deleting local snapshots does not delete your Time Machine backups on the backup drive.

What local snapshots are

When Time Machine is set to back up automatically, macOS saves a snapshot of your startup disk about once an hour and keeps each one for up to 24 hours. They let you restore a file even when the backup drive is not plugged in.

The space they use is counted as available by Finder, because macOS will delete snapshots when something else needs the room. That is why Finder and Storage settings can show different amounts of free space. Sometimes an app or installer still reports that there is not enough space, and removing snapshots by hand fixes that.

1. List your snapshots

Open Terminal (Applications → Utilities) and run:

tmutil listlocalsnapshots /

Each line ends with a date stamp such as 2026-11-01-093000. If nothing is listed, there are no local snapshots.

2. Delete snapshots in Terminal

Delete one snapshot by its date stamp:

sudo tmutil deletelocalsnapshots 2026-11-01-093000

Delete all of them:

for d in $(tmutil listlocalsnapshotdates / | grep -v :); do sudo tmutil deletelocalsnapshots $d; done

Or ask macOS to free a set amount. This asks for about 20 GB at the highest urgency:

tmutil thinlocalsnapshots / 20000000000 4

You will be asked for your Mac password for the sudo commands. Nothing appears as you type it.

3. Delete snapshots in Disk Utility

  1. Open Disk Utility (Applications → Utilities).
  2. Choose View → Show APFS Snapshots.
  3. Select your data volume in the sidebar, usually Macintosh HD - Data or Data.
  4. Select a snapshot in the list at the bottom and click the minus button.

Note: a snapshot named com.apple.os.update belongs to macOS itself. Leave it alone.

Stop new snapshots

Local snapshots are only made while automatic backups are on. To stop them, open System Settings → General → Time Machine → Options and set the backup frequency to Manually. Your Mac will then only back up when you choose Back Up Now, so do this only if you will remember to.

Frequently asked questions

Is it safe to delete Time Machine local snapshots?

Yes. Local snapshots are short-term copies kept on your startup disk. Deleting them does not delete the backups on your Time Machine drive. You only lose the ability to restore files from the last 24 hours while the backup drive is disconnected.

Do local snapshots take up space on a Mac?

Yes, but macOS treats that space as available and deletes snapshots automatically when it is needed. Finder counts it as free, while some apps and Storage settings may not.

How long does a Mac keep local snapshots?

Up to 24 hours each. macOS makes roughly one per hour while automatic Time Machine backups are on, and removes older ones or removes them sooner when disk space runs low.

How do I delete all local snapshots at once?

Run this in Terminal: for d in $(tmutil listlocalsnapshotdates / | grep -v :); do sudo tmutil deletelocalsnapshots $d; done. It lists every snapshot date and deletes each one.

Why do local snapshots come back after I delete them?

macOS creates a new one about every hour while automatic Time Machine backups are on. To stop them, set Time Machine to back up manually in System Settings → General → Time Machine → Options.
