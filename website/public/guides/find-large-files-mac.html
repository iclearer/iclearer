How to find large files on Mac

Updated 12 November 2026 · By the iClearer team

Short answer

The quickest way to find large files on a Mac is System Settings → General → Storage: click the i next to Documents and open the Large Files tab. You can also search by size in Finder (press Command F and add a File Size filter) or list every file over 1 GB in Terminal with find ~ -type f -size +1G.

1. Storage settings

  1. Open the Apple menu → System Settings → General → Storage.
  2. Click the i next to Documents.
  3. Open the Large Files tab. Files are sorted biggest first, with the date you last opened them.
  4. Select a file and click Delete, or Show in Finder to look at it first.

The Downloads tab in the same window is worth a look too.

2. Finder search by file size

  1. Open a Finder window and press Command F.
  2. Make sure the search covers This Mac.
  3. Click the first filter menu (it says Kind) and choose Other…
  4. Find File Size in the list, tick it and click OK.
  5. Set the filter to is greater than 1 GB.

Lower the number to 500 MB to see more. By default Finder’s search leaves out hidden and system folders, so it will not show files inside the Library.

3. Terminal

This lists every file over 1 GB in your home folder, with its size, including hidden ones:

find ~ -type f -size +1G -exec ls -lh {} + 2>/dev/null

To see which folders are largest instead:

du -sh ~/* 2>/dev/null | sort -h | tail -15

What is usually big

  • Videos and screen recordings in Movies, Desktop and Downloads
  • Virtual machines from Parallels, VMware or UTM
  • Disk images and installers (.dmg, .iso, .pkg)
  • Old iPhone and iPad backups in ~/Library/Application Support/MobileSync/Backup
  • Archives you already unzipped
  • Downloaded AI models and other developer files, covered in the developer guide

Before you delete

  • Select a file and press Space to preview it with Quick Look.
  • Move files to the Trash rather than deleting them outright, and empty the Trash once you are sure.
  • For anything you cannot replace, check that your Time Machine or iCloud backup is recent first.

Frequently asked questions

How do I see what is taking up space on my Mac?

Open System Settings → General → Storage. The bar shows space by category, and the i button next to each category lists what is inside. For a folder-by-folder view, run du -sh ~/* in Terminal or use a storage map tool.

How do I find files larger than 1 GB on a Mac?

In Finder, press Command-F, add a File Size filter and set it to is greater than 1 GB. In Terminal, run find ~ -type f -size +1G to list them, including files in hidden folders.

Why can I not find the large files using my storage?

They are probably in hidden folders. By default Finder’s search leaves out the Library folder, where caches, app data, device backups and developer files live. Use the Terminal command or a tool that scans the Library.

Is it safe to delete large files in the Library folder?

Sometimes. Caches and old device backups are safe to remove, but Application Support folders hold data for apps you use. Check what a file belongs to before you delete it, and move it to the Trash first so you can put it back.

What file types usually take the most space on a Mac?

Videos, virtual machines, disk images, old iPhone backups and photo libraries. On developer Macs, simulator data, Docker images and downloaded AI models are often larger still.
