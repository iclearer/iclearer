iClearer developer handoff
==========================
Start with the Claude doc: "iClearer developer handoff" (the account owner will share the link).

Contents
- prototypes/iclearer-app-prototype.html   Open in a browser on a desktop. Clickable app design (not production code).
- prototypes/iclearer-landing.html          Landing page prototype. Reusable as a starting point.
- design-tokens.json                        Colors, radii, spacing, type, section icon colors, plan prices.
- brand/logo-pack/                          SVG and PNG logos, favicon, layers for the app icon.
- brand/iClearer-identity-presentation.pdf  Brand system presentation.
- brand/iClearer-which-logo-to-use.pdf      One page: which logo to use where.

Notes
- The HTML files are design prototypes. Build the app natively in Swift.
- All sizes, file names, apps and numbers in the prototypes are made-up examples.
- Stats, testimonials and ratings on the landing page are marked Placeholder. Replace or remove.
- Prices are starting prices to test, not final.
